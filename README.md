# Hospital Readmission Analysis Dashboard — Excel

## Project Overview

The Hospital Readmission Analysis Dashboard is a healthcare data analysis project developed using Microsoft Excel. The project analyzes 66,587 hospital patient encounters to understand readmission patterns based on previous inpatient visits, emergency visits, age groups, and medical specialties.

The analysis uses data cleaning, PivotTables, PivotCharts, KPI calculations, and interactive slicers to create a dashboard that presents key findings and recommendations.

---

## Project Aim

To analyze hospital readmission patterns and identify patient groups and areas with higher observed readmission rates using Excel-based data analysis and visualization.

---

## Objectives

- Analyze the overall hospital readmission rate.
- Examine readmission patterns based on previous inpatient visits.
- Analyze readmission patterns based on previous emergency visits.
- Compare readmission rates across different age groups.
- Compare readmission rates across medical specialties.
- Create an interactive dashboard to present key findings.
- Develop recommendations based on observed data patterns.

## Analysis Performed

### Previous Inpatient Visits

Analyzed readmission rates based on the number of previous inpatient visits.

The observed readmission rate increased from 38.66% to 82.74% across the categories shown in the dashboard.

### Previous Emergency Visits

Analyzed readmission rates based on previous emergency visits.

The observed readmission rate increased from 44.04% to 84.43% across the categories shown in the dashboard.

### Age Group Analysis

Compared readmitted and non-readmitted encounters across different age groups ranging from 0–10 to 90–100.

### Medical Specialty Analysis

Compared readmission rates across different medical specialties.

Among the specialties shown, Nephrology recorded the highest readmission rate at approximately 55.1%.

---

## Key Insights

- The overall readmission rate was 46.20%.
- Higher numbers of previous inpatient visits were associated with higher observed readmission rates.
- Higher numbers of previous emergency visits were also associated with higher observed readmission rates.
- Nephrology had the highest readmission rate among the specialties shown.
- The dashboard allows analysis through age group and medical specialty filters.

Note: These findings represent observed patterns in the analyzed data and do not establish causal relationships.

---

## Recommendations

Based on the observed patterns:

- Improve discharge planning and follow-up processes.
- Monitor patients with higher previous inpatient or emergency visit history.
- Focus attention on specialties with comparatively higher readmission rates.
- Consider enhanced follow-up for higher-risk patient groups.
- Use dashboard insights to support data-driven healthcare decisions.
